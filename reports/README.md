# Community reports

This directory is for original, sanitized security research and retrospective
reports that are safe to publish.

Before adding a report:

- Confirm authorization and coordinated-disclosure obligations.
- Remove secrets, personal data, customer identifiers, internal addresses, and
  details that create unnecessary operational risk.
- Describe scope, dates, methodology, evidence quality, limitations, and confidence.
- Link primary sources and distinguish observed facts from inference.
- Include mitigations and a clear defensive benefit.

Name reports `YYYY-MM-DD-short-title.md`. Start from the relevant file in
[`templates/`](../templates/) and replace all placeholders.
