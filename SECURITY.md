# Security policy

StrangerThreats is a documentation repository and does not operate a production
service. Please use GitHub Issues for public content errors that do not expose
sensitive information.

Do not open a public issue containing credentials, personal data, undisclosed
vulnerabilities, customer details, or evidence from an active incident. Use the
repository owner's private contact channel or GitHub private vulnerability
reporting when it is enabled.

This project does not accept requests to investigate third-party systems or to
publish exploit instructions against real targets.
