# Career and certification paths

Choose a role before choosing an exam. Certifications can structure study and
signal a baseline, but projects, writing, judgment, and real operational experience
are stronger evidence of capability.

## Shared foundation

Build competence in operating systems, networking, identity, scripting, Git,
cloud basics, logs, risk, and clear technical writing. Create a small portfolio:
a threat model, a detection with tests, an incident timeline, a hardening guide,
and one concise security report.

## Role-based paths

| Direction | Practice first | Optional certification examples |
| --- | --- | --- |
| Entry-level / career change | Home lab, networking, log analysis, security fundamentals | [ISC2 CC](https://www.isc2.org/certifications/cc), [CompTIA Security+](https://www.comptia.org/en-us/certifications/security/) |
| SOC / detection / incident response | SIEM queries, endpoint telemetry, packet analysis, playbooks | [Cisco Cybersecurity Associate](https://www.cisco.com/site/us/en/learn/training-certifications/certifications/cybersecurity/associate/index.html), [Microsoft SC-200](https://learn.microsoft.com/credentials/certifications/security-operations-analyst/) |
| Threat intelligence | Collection plans, source evaluation, ATT&CK mapping, structured reports | Vendor-neutral CTI training; role-relevant [GIAC certifications](https://www.giac.org/certifications/) where budget permits |
| Penetration testing | Legal lab work, methodology, evidence, remediation writing | [OffSec OSCP](https://www.offsec.com/courses/pen-200/), role-relevant GIAC certifications |
| Application security | Secure coding, threat modeling, code review, CI/CD controls | Use [OWASP learning resources](https://owasp.org/projects/) first; add a language/cloud credential only when role-relevant |
| Cloud security | IAM, logging, network controls, policy-as-code, recovery | [AWS Certified Security - Specialty](https://aws.amazon.com/certification/certified-security-specialty/), [Microsoft AZ-500](https://learn.microsoft.com/credentials/certifications/azure-security-engineer/), [Google Professional Cloud Security Engineer](https://cloud.google.com/learn/certification/cloud-security-engineer) |
| Governance, risk, and leadership | Risk registers, control evidence, audit, policy, business communication | [ISACA certifications](https://www.isaca.org/credentialing/certifications), [ISC2 CISSP](https://www.isc2.org/certifications/cissp) after meeting experience requirements |

Examples are not rankings or mandatory sequences. Check official prerequisites,
exam outlines, renewal rules, language availability, and total cost before paying;
these change over time.

## A practical decision rule

Pursue a certification when at least two are true:

- Target job descriptions repeatedly request it.
- Its curriculum closes a known skill gap.
- An employer funds it or it unlocks a formal requirement.
- You can pair it with a project that demonstrates the skill.

Delay it when the main motivation is collecting badges, when fundamentals are weak,
or when the cost would displace higher-value practice.

## Portfolio checklist

- State authorization and scope for every security exercise.
- Explain decisions and uncertainty, not just commands and screenshots.
- Redact sensitive data and use synthetic examples.
- Include tests, failures, improvements, and what you would do next.
- Link small, maintained artifacts instead of one enormous lab dump.
