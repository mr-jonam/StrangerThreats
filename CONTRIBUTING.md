# Contributing to StrangerThreats

Thank you for improving the knowledge base. Contributions should make security
knowledge easier to verify, apply, and communicate.

## Good contributions

- Correct an inaccurate or stale statement and cite the primary source.
- Add a lab-safe workflow, decision aid, or sanitized report.
- Improve a role-based learning path without turning it into an exam advertisement.
- Add a maintained tool with a clear use case, license, and official link.

## Before submitting

1. Search existing pages to avoid duplication.
2. Keep offensive material scoped to owned labs or explicitly authorized work.
3. Remove secrets, customer names, internal addresses, and personal data.
4. Distinguish facts, observations, assumptions, and conclusions.
5. Run `pwsh -File scripts/Test-Repository.ps1` from the repository root.

## Source policy

Prefer standards bodies, government agencies, research papers, and first-party
vendor advisories. Secondary sources are useful for context but should not be the
only support for material claims. For changing information, include `Reviewed:
YYYY-MM-DD` near the references.

## Pull requests

Use a focused title and explain the problem, evidence, change, and validation.
